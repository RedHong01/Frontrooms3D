# Working in this repository (people and AI tools)

- **Project state is not in this repository.** The course folder that contains this repo has `Documentation/Takeover_2026-10-18/START_HERE.md`: the rules, one state file per work line (`handoff/<line>.md`) and the progress ledger. If you can only see this repo, ask the project owner for the current state; do not infer it from old documents.
- **Design and research documents live under `Documentation/`, one folder per topic** (`Documentation/research/<topic>/`). Update the existing document in place. Before you create a markdown file, search for the topic (`grep -ril "<words>" Documentation`); if one exists, edit it.
- Do not create status, summary, copy, `v2` or dated duplicates of a document. File names carry no author, tool, account, version or date.
- Every research folder keeps its real, dated sources in `SOURCES.md`. Third-party media and licensed audio never go into this repository.
- Do not commit credentials, tokens, local machine paths or personal names; this repository is public. Only the project owner commits and pushes.
