## 1. 背景：专业 TA 怎么做，我们做了什么

专业技术美术的顺序是：先测，再找"花了钱却看不见"的部分，把它省下来，再把省下来的预算花在玩家看得见的地方。具体做法：
- 关着的门就是关着的"门户"（Doom 3、Source 引擎都这么做）：门后的房间不画、不亮灯。
- 阴影只给真正有东西投影的灯。
- 同样的画面用更少的采样（例如环境光遮蔽 SSAO）。
- 少用"每个物体一份参数"（MaterialPropertyBlock），让引擎能把物体合批。
- 用贴花（decal）和修边贴图（trim sheet）表现磨损和细节，而不是靠着色器算出来的花纹。
- 每个平台一套画质：桌面版是标准，手机和网页单独一套，绝不改动桌面版。

我们在工作站克隆（proj_build，和主工程同步）里实测了标题无限走廊的 3 个画面和普通楼层（Level 0）的 3 个画面：每一项都单独关掉再打开，统计 draw call、阴影、灯光，并逐像素对比画面。结果：
- 走廊一帧约 850 次 draw call，楼层 4,800–7,400 次。
- 其中三分之一到一半花在阴影上，五分之一到三分之一花在"深度预通道"上。
- GPU 上最贵的一项是环境光遮蔽（SSAO）：在高分辨率下关掉它，帧时间少 30–60%。但它在画面上看得出来（3–10% 的像素变暗），所以要保留，只是换个更省的设置。

所有对比图都按 Shot 格式放在 `sheets/`。

### A. 清单交给游戏视觉和关卡设计按顺序做（推荐：同意）
- 背景：我这条线不落地任何渲染文件，只出提案和克隆原型。

  - 同意：游戏视觉从第 1 项开始，和正在做的走廊新房型（title_stream）一起做。玩家不会看到差别，走廊和楼层都会更轻，新房型加进来时不会变卡。

### B. 方向补光的阴影要不要关（推荐：关）
- 背景：这盏补光强度 0.16，阴影强度只有 0.18，却画了一整张 2048 的两级阴影图，占 12–16% 的 draw call。
- 你会看到的：对比图 `ta03_directional_fill_shadow.jpg`。没有任何像素变化超过 8/255，只剩 1–3/255 的极淡轮廓，并排也很难看出。
- 推荐：关。缺点是理论上那 1–3/255 的极淡暗影会没有，所以请你看一眼图再定。

### C. 走廊 60 道"体积光束"要不要拿掉（推荐：从空房间拿掉，有灰尘感的房型以后再做好看的）
- 背景：每个灯盘下有一道叠加光束，亮度峰值只有灯光的约 1%，在 Lobby 画面里几乎看不出（0.02–0.26% 像素变化），却每帧多 8–18 次 SetPass。
- 选项：
  - 拿掉：空房间画面一样；需要的话，在 Pool / 有灰尘的房型做带深度淡出的真实光柱（会好看很多）。
  - 保留：保持现状。
- 推荐：拿掉，以后按房型重做。

## 4. 诚实说明
- 核对时发现一件可能影响桌面版标准画面的事（还没在打包版里亲眼确认）：游戏里的灯是代码直接创建的，打包出来的 Mac/Win 版里阴影边缘可能用的是"低"质量过滤，而编辑器里显示的是"高"。如果确认，修法很小（创建灯时加一个组件），打包版就和你在编辑器里看到的一样。已列为第 16 项，先抓帧确认。
- GPU 每一步的毫秒数还没有：这台 Mac 的批处理模式没有 GPU 计时，需要用 Xcode 抓 Mac 版游戏的帧。清单里写的是 draw call 和像素对比，这些是准确的。
- 没在 iPhone / iPad / Windows 上测（商店冻结、没有 PC）。
