## 背景：为什么现在问

联合测试（11-02/11-03）有一张截图：玩家在怪物身后 3 米，看起来怪物的"头"插进了天花板的灯里。你给怪物定的方向是：
"我希望怪物能够像是巨大的身躯挤在小小的这个空间里"，肩背离天花板只有 2-5 厘米（`research/hunter/11_squeezed_giant.md`）。

我们在克隆工程里用正式的怪物模型逐帧量了（每个方案 85,490 帧），结论：

1. **顶到灯的不是头，是上背（肩膀后面的那块隆起）。** 头一直在天花板下 8-14 厘米。
2. **走路时其实没碰到灯。** Level 0 的灯（L03）边框比天花板低 2.4 厘米，怪物上背比天花板低 2.7 厘米，中间有 3 毫米。
   但从身后看，深色的背直接压在亮的灯面上，而且灯的光源在背的下面，背的顶上一点光都没有，所以看起来像"插进去了"。
3. **两个动作真的插进去了：** 锁定玩家的那一下（插进边框 9 毫米）和砸门（插进边框 23 毫米，碰到灯片）。
4. **今天 18:47 主工程加了新灯，问题更大：** 办公室的吊灯垂下来 60 厘米，怪物走过时整个上半身直接穿过吊灯（最深 60 厘米）；
   后场低矮走廊的长条灯也会被穿过（最深 8 厘米）。这是现在游戏里就有的真穿模，不管你选哪个方案都应该修。

所以每个方案（A、B、C）都带同一套"底子"：怪物身体的真实最高点永远离天花板或灯框 3 毫米；遇到吊灯、长条灯这种往下
垂的灯，身体提前压低从下面过；听声音时右手手套贴在一块普通的天花板上，不会按在灯上。量下来，A、B、C 三个方案在所有动作
里都是 **0 次穿模**。真正要你选的，是 Level 0 那种嵌入式灯下面"看起来"怎么处理。

## 第 1 项：怪物经过 Level 0 的灯时，怎么处理

| 方案 | 玩家看到什么、感觉到什么 | 成本 |
|---|---|---|
| **今天** | 深色的背压在亮灯面上，背顶是黑的，像插进灯里。锁定和砸门时真的插进去。 | 不改代码，但穿模都还在 |
| **A 灯下低头弯腰** | 每经过一盏灯，整个身体往下沉 12 厘米，过了灯再慢慢起来。从身后看，背和灯之间有一条亮缝，灯光也能照到背上。但是 Level 0 的灯每 3 米一盏，怪物一直在"沉下去、半起来"，一路离天花板 10-15 厘米，你要的"挤在小空间里"在 Level 0 基本没了；听声音时手也够不到天花板。还有一个风险：每到一盏灯就缩一下，可能被理解成"怪物怕光、在躲灯"。 | 约 +580 行代码；每帧多约 0.1 毫秒 |
| **B 灯下低头** | 只有脖子和头往前低 13 度，肩背还贴着天花板。可是顶到灯的是背不是头，所以接触的地方一点没变；而且从身后看根本看不到头（那张截图的角度和今天一模一样）。从正面看，每到一盏灯头就点一下，也可能被理解成"怕光"。 | 约 +590 行；每帧多约 0.06 毫秒 |
| **C 接触感（推荐）** | 姿势不变，还是贴着天花板走（离天花板 2.7 厘米，正好在你说的 2-5 厘米里）。经过灯下时，灯光照亮它背顶的那块隆起，它脚下的地面暗一点，像真的有个巨大的身体从灯下面挤过去、蹭着灯走。灯本身不变（不闪、不变暗，符合"怪物在的地方灯不变"的规则）。它不躲光，直接从光里走过去，被光照到。 | +725 行（已打成包）；怪物在亮灯下时多 1 盏小灯和地上 1 片阴影；每帧多约 0.06 毫秒 |

（毫秒数是重启后机器很忙的时候测的，只能比大小，不能当预算。）

**推荐 C。** 理由：它保住了你要的"挤在小空间里"，把"插进灯里"变成"压在灯下面"，再加上底子，所有真穿模都没了。
A 牺牲了 Level 0 的挤压感，还一直上下晃；B 改的地方根本不是接触的地方，从截图那个角度看不出区别；A 和 B 都有"像怕光"的风险。

**C 的诚实缺点：**
- 从身后 3 米看，背还是会盖住灯面的下半截。真实世界里一个身体贴在灯下 3 毫米也是这样，所以 C 让它读成"压在灯下"，
  但如果你期待看到一条缝，C 不会给你缝（要缝只有 A）。
- 背上的光是用一盏小灯模拟整块灯面的光；地上的阴影是一片柔和的暗斑，不是身体的精确影子形状。
- 灯坏了（不亮）的时候，背上就没有光了，这时看起来和今天一样（这是对的，但没有额外效果）。

## 第 2 项：办公室吊灯和后场长条灯下面，怪物怎么过

现在：直接穿过去（见对比图 PENDANT 那几行的"今天"一列，吊灯插在背里）。

包里的做法（推荐）：遇到吊灯，身体提前压低，从吊灯下面过，离吊灯底 2.5 厘米。代价是：办公室的走廊每 3 米一盏吊灯，
怪物在办公室里几乎一直是蹲低的姿势（就是它在 2.4 米低矮走廊里的那个姿势），办公室里它看起来更矮、更挤。后场长条灯只压低
约 8 厘米，几乎看不出来。

另一种做法（不推荐，也不是我们这条线能定的）：请关卡设计/灯具适配不把吊灯挂在怪物走的走廊中线上。那样怪物在办公室能
保持站高，但要改地图和灯的布置。

## 第 3 项（不用选，告诉你一声）：听声音时的手

设计里写的是"听的时候右手平放在天花板上"，但现在手离天花板差 10 厘米，有时候正好在灯下面，看起来像手按在灯上。
三个方案都把手放到旁边一块普通的天花板上（必要时手臂往外转最多 50 度）。有约 5% 的位置附近转不到普通天花板，这时手就
停在原来的位置（离天花板 10 厘米），不会按到灯上。
