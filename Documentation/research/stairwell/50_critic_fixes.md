## Rejected

Nothing outright. Two points went further than the critic asked, with the reason given:
- **Era 3 / Gameplay 2:** the critic kept a down-gate at the far landing; I removed the flight below instead, so no gate exists. Reason: 叙事's stair ID string already describes a two-level stair, there is then no device to borrow, and no flight in the well invites "can I go further down?".
- **Era 1, "far door brightest":** I did not force the far door to be the brightest thing; I withdrew the claim. Making a door the brightest object would need a spot aimed at it, which reads as a cue light inside a room the game calls safe.
