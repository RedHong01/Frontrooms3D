**State:** **confirmed** = the verifier opened the source and found the value (any correction is given); **not confirmed** = the source could not be read or did not show the value (it may still be right; it is not cited in `10_research.md`); **forum** = secondary support only, not re-checked.

Pages were read online only. No media was downloaded, and no third-party file is kept in the repo. Raw results: `~/FrontRoomsVisualWork/crt_border/research/all_findings.json`.
