# Room visuals: wanted media (NOT downloaded)

Nothing in this list has been downloaded. Downloads need Red's explicit approval. The visual chat will ask Red once for the whole batch.

How to read a row:
- **Page URL** is the page to open and check (licence, author, date).
- **Direct URL** is what a downloader would fetch, when known. For Wikimedia Commons, `Special:FilePath/<name>?width=1920` returns a 1920 px thumbnail, so nothing larger than needed is fetched.
- **Size** is approximate. "≤ 1 MB" for a 1920 px Commons thumbnail is an estimate; the original may be larger.
- **Proves** says what the file would show on a slide.
- After download, each file gets a row in `SOURCES.md` (URL, date, licence) and is saved as JPG q85, max 1920 px wide, under `images/` or `Research/week02/room-visuals/`.

Other steps of this workflow may append their own sections below.
