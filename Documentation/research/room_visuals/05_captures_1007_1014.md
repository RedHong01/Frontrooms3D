# 05 — Room captures of 7 Oct and 14 Oct: what each set is, and what changed

Date: 2026-10-14. This is the written report for the two later capture sets. The 3 Oct set is described in `04_captures.md`, and its recipe still holds: the same harness, the same 65 shots, seed 4242 (run 516574485), captures rooted at multiples of 192 m, vFOV 72 (the game camera uses 76).

## 0. Short answer

- **7 Oct set** (`images/room1007_*`): main `ee5c9bb`. This is the set the Figma section was built from on 10-08.
- **14 Oct set** (`images/room1014_*`): main `0a9ee7f` plus its working tree, re-synced into `W/proj_rooms_1008` at 16:18. Compile: 0 errors. Capture: 65 frames in 46 s.
- **61 of 65 frames are the same as on 7 Oct.** On those, 0.0 % of pixels move by more than 0.08 (any channel, sRGB, on 480 × 270 copies). This covers the start rooms, every map room, Office, Tall, columns, borders and lamp moods.
  - `bc0aa79` (10-08) and `2ce2087` (10-10) changed code, but none of it shows in these frames.
  - The Office kit change was time-sliced dressing (3 ms a frame). It gives the same result, only spread over frames.
  - The EGRESS placard mounts on the map side, at (255.08, 1.56, 19.5). That is about 15 m into the map, out of the start-room frames (`[Placard] mount P2 west` in the capture log).
- **4 frames changed: the title Run and Exit rooms.** These are the merged EXIT kit (10-08 19:5x):
  - Run rooms: two `Kit_ExitSign_Hanging` replace the code-built Arial signs. Up to 5.6 % of pixels move (`title-run_ceiling`).
  - Exit rooms: a small wall `Kit_ExitSign` now sits over the far door. Under 0.08, so it does not count above, but it is visible in `title-exit_arrival` and `_ceiling`.
- The 10-08 attempt of this fix stage made an identical set on `bc0aa79` plus the EXIT merge (`W/rooms_fix/jpg1008`). It is not kept in the doc folder; the 14 Oct set equals it on every frame.

## 2. What the frames do not show (unchanged since 3 Oct)

- **Shift, Office, Run and Exit are still never reached.** `lobbyOnlyTitle` is true (`FrontRoomsRoomStream.cs:78, 322`). Only the editor test `FrontRoomsStreamVerification.cs:80` calls `BeginPlayableSequence()`.
- **The Exit room's "threshold marker" strip is never built.** The shot `62_title-exit_threshold` frames bare carpet. The `if` at `FrontRoomsRoomStream.cs:1449` takes Lobby, Shift and Exit, so the `else if (rule == RoomRule.Exit)` branch at 1513–1515 never runs. The comment at 1458–1459 says so. The harness still names the shot after the strip; the slides no longer do.
- **No module room is framed on its own** (L10). None of `L0_WaitingRoom_4x3`, `Low_Storage_2x3`, `Office_Bullpen_4x4` or `Tall_PillarHall_6x5` is shown. The generator places modules only where it decides, the capture seed's framed cells hold none, and framing one needs a harness change (find a module cell in seed 516574485, add a shot). Listed as a follow-up in `40_for_red.md`.
- **The game camera is 76°; the harness renders at 72°.**
