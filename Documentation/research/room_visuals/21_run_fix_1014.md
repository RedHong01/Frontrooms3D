# 21 — Run! directions: the fix pass (floors, Relay size, open gaps)

Date: renders 2026-10-08 20:04–20:10 (fix stage, cut off by the usage limit at about 20:12), checks and report 2026-10-14 16:2x–17:xx.
Scope: the critic's H1, M5–M8, M12 and L8 for the three Run! pre-renders. Clone-only. Nothing was merged, and Red's project was not opened in Unity.

## 0. Short answer

1. **All three floors now meet Red's 10-03 decision.** A and C were re-rendered with B's probe fix. Their box probes now reach the floor (magenta test: 97 % of A's floor, 95 % of C's).
2. **The probes matter in A, not in C.** In A they change 61 % of the frame. In C they change 0.25 %: C is bright, so the strips' own highlights carry the gloss.
3. **At the Relay's real size (2.05 m), A fails.** A reads 2.97 : 1 (bar 4 : 1). B reads 7.68 : 1. C reads 9.36 : 1 off axis and 6.67 : 1 on axis through the lites.
4. **The pick stays B (Emergency Power).** The floors are now equal, A fails the Relay bar at true size, and C breaks its own flash rule.

## 2. H1: the floors

### 2.1 Do the probes reach the floor? (VL236)

Magenta / green test (B's r6 method): every box probe gets a solid magenta cube and the default reflection a solid green one, before the first render. Measured on S1b, with the floor ROI = the bottom 30 % of the frame, middle 40 %:

| Direction | Frame magenta | Floor ROI magenta | Green anywhere |
|---|---|---|---|
| A · Red Ward | 94.6 % | 97.1 % | 0 % |
| C · House Lights | 33.3 % (the matte walls tint pink, under the counting threshold) | 95.1 % | 0 % |
| C, baked as B does | 33.3 % | 95.1 % | 0 % |
| B (VL195, 10-08) | — | probes cover every shell pixel | — |

- **A:** the first A_dbg run (10-14) showed no magenta. The rig re-applies its per-state texture lists on every `Evaluate`, so it overwrote the debug cubes. A_dbg2 also replaces the lists, and then the floor turns magenta.
- **C's in-run bake was not the problem.** Custom mode and Baked-then-Custom give the same coverage once the boxes overhang the shell. The 10-08 open point ("C's probes are probably inert") was the box size alone.

### 2.2 What the probes change (same shot, probes on vs off)

| | A · Red Ward | C · House Lights |
|---|---|---|
| Default reflection when probes are off | the empty scene's sky | the Level 0 zone cube |
| 8 px blocks that move by more than 5 % | **61.2 %** | **0.25 %** |
| Pixels that move by 3 levels or more | 79.9 % | 0.18 % |
| Floor ROI mean, linear Y, on / off | 0.161 / 0.167 (−3.6 %) | 0.153 / 0.153 |
| Saturated red (R/(R+G+B) ≥ 0.8) | 32.0 % / 13.2 % | 0 / 0 |

- A's floor now mirrors the red signs and the dark corridor instead of a grey sky. That raises the red share, and the frame stays inside A's 25–50 % red target.
- C's floor was already lit by its own strips. At these light levels a 4 % dielectric reflection adds almost nothing, so the visible sheen comes from the strips' direct highlights. This matches B's finding: "steep views change little" (`20_run_emergency_power.md` §1.2).

## 3. M6: the Relay at its real size (VL237)

All values are linear Y, comparing the Relay's body with a 12 px ring around it. For C, the ring is kept inside the lites. The same run renders both sizes, on the fixed floors.

| Direction | Brief proxy (top 1.84 m) | Contract size (top 2.05 m) | Bar ≥ 4 : 1 |
|---|---|---|---|
| A · Red Ward | 6.34 : 1 (protan 8.87) | **2.97 : 1** (protan 3.73) | **FAIL at true size** |
| B · Emergency Power | 8.07 : 1 (protan 8.12) | **7.68 : 1** (protan 7.74) | PASS |
| C · House Lights, on axis | hidden (0 px through the lites) | 6.67 : 1 through the lites, but only 136 px visible | PASS, barely seen |
| C · House Lights, 0.65 m off axis | 4.42 : 1 (5.20 before the probe fix) | **9.36 : 1** | PASS |

- **Why A drops.** The taller body reaches into the hanging signs' spot cones. Its mean Y rises from 0.037 to 0.063, while its ring falls from 0.23 to 0.19. A dark Relay under red spots is lit by them.
- **Why C rises.** The taller head shows in the lites against the bright far compartment.
- **The game rig.** It is 3.05 m and does not fit the 2.9 m corridor. A measured it at 3.15 : 1 (`11_run_dir_red_ward.md`). Red's squeezed-giant direction has no model yet (`research/hunter/11_squeezed_giant.md`). The stand-in tests the contract size, not the final silhouette.
- **Every earlier Relay number** on RV26–RV28 and RV31 came from the 1.73–1.84 m proxy. The slides now say "proxy" and give the 2.05 m value next to it.

## 5. The pick, re-checked

The floors are now to spec in all three, so the comparison on RV30 is fair. The pick stays **B · Emergency Power**:
- B is the only direction that passes the Relay bar at both sizes.
- A fails at the true Relay size (2.97 : 1).
- C hides an on-axis Relay behind its shut pairs. Its red flashers break rule 4. It is the most expensive: 22 tripped lights, 153 MB of new textures.

B's own open items are unchanged: the near head's spill outshines the goal, the cart reads 1.16 : 1, and contrast 8 with red 1–3 % does not fit the pool target.
